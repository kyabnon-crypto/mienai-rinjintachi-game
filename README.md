# 見えない隣人たち — 常世町プレイアブル作品集

『**見えない隣人たち**』の世界観・キャラクター・公式楽曲3アレンジ・実3Dモデル（`.glb`）を活用した、スマホ横画面＆WebGL対応の3Dゲームコレクションです。

---

## 収録タイトル

### 05. 自販機裏のぬくもり番 〜ヌクモリ〜（NEW!）
- **ジャンル**：3D 真冬の自販機裏＆ベンチ温度番アクション（[`nukumori.html`](nukumori.html)）
- **舞台**：凍える真冬の街角「古い自動販売機の裏の小屋『おんどばん』＆公園のベンチ広場」
- **特徴**：
  - リグ・アニメーション済み `nukumori.glb`（`Walking` / `Running`）＋正面が青白く光る自動販売機・裏面の放熱ファン＆煙突・動く真鍮ダイヤルの古い温度調整機・5本の赤い水銀温度計・だるまストーブ＆銅やかん・ほかほか缶ウォーマー・赤いマフラー・チェック柄毛布ベッド・白い息の小瓶棚・「おつかれさまです」マグカップ・4基の冬のベンチを3D空間で再現。
  - 冷え込んでいく4つの公園ベンチ（自販機わき・公園ベンチ・並木道ベンチ・バス停ベンチ）をタップ / ドラッグ / WASD で見回り、そっと手を置いてじんわり適温へ温めよう。温め完了で帰り道のシルエットがほっと微笑み、5種のぬくもりの種を集めて「おつかれさまオーダー」や「あったか〜い缶ラック差し入れ」を達成！
  - **湯気ウェーブ（STEAM WAVE）**で凍える北風を一斉融解して「白い息」へ変換＆4つのベンチを一気に保温。
  - ゲージMAXで **POKAPOKA NIGHT（ぽかぽかの夜）**発動！真冬の雪が黄金の湯気雪に変わり、全北風がレア「ほっと星湯気」へ変化＆全ベンチ自動保温・ぬくもり2倍の極上フィーバー！
  - 公式3アレンジ（`Dreamy Ver.` / `通常版` / `Instrumental` 各62秒ゲームサイズ）、6種類の温度番小屋設備強化（古い温度調整機・裸電球と吊り看板・だるまストーブと銅やかん・ほかほか缶ウォーマー・赤いマフラーと毛布のベッド・白い息の小瓶とマグカップが3D空間に反映）、物語『第五話：自動販売機の裏の温度番』全5章を収録。

### 04. 街灯の下のわすれ玉 〜ワスレダマ〜
- **ジャンル**：3D 夜の街角広場・わすれ玉回収＆そっとお届けアクション（[`wasuredama.html`](wasuredama.html)）
- **舞台**：誰もいない夜の住宅街「街灯の下の落とし物置き場」
- **特徴**：
  - リグ・アニメーション済み `wasuredama.glb`（`Walking` / `Running`）＋街灯の光の輪・「わすれもの」吊り看板・雨上がりの水たまり・大きな麻袋・希望の小瓶＆約束の結び糸・古いノート「わたしの夢」・「まだ必要な人へ」仕分け棚・ストリングライトを3D空間で再現。
  - タッチドラッグや WASD / 矢印キーで石畳の夜道を自由に歩き、5種類の「物ではない忘れ物」（言いかけてやめた夢・途中で諦めた約束・心の奥にしまった希望・古いノート・星灯りのわすれ玉）を布袋へ集めて、「まだ必要な人」のそばへそっと届けよう。
  - **灯りパルス（LAMP BLOOM）**で周囲の「ためらいのもや」を一斉浄化＆近くの忘れ物を布袋へ引き寄せ。
  - ゲージMAXで **STARLIT STREET（星明かりの夜道）**発動！街灯と吊り電球が満天の星明かりのように輝き、すべてのもやが星灯りのわすれ玉へ変化＆2倍スコアの爽快フィーバー！
  - 公式3アレンジ（`Dreamy Ver.` / `通常版` / `Instrumental` 各62秒ゲームサイズ）、6種類の街角設備強化（街灯のあかり・夜道の吊り電球・たいせつな布袋・仕分け棚・希望の小瓶と結び糸・古いノートが3D空間に反映）、物語『第四話：街灯の下の忘れ物係』全5章を収録。

### 03. 時繋ぎの懐中時計 〜トキツギ〜
- **ジャンル**：3D 押し入れ時計工房・懐中時計リズム修繕＆金の糸つなぎ（[`tokitsugi.html`](tokitsugi.html)）
- **舞台**：どの家の押し入れの奥にもある「わずかな隙間の時計工房」
- **特徴**：
  - リグ・アニメーション済み `tokitsugi.glb`（`Walking` / `Running`）＋作業台の中央に広がる巨大な3D真鍮懐中時計＆噛み合う5枚の歯車を搭載。
  - 楽曲のビートに同期して回る「光の針」に合わせてタップ / Space（または欠片を直接タップ）すると、トキツギの手元から3D空間に「金色の糸」が伸びて5種類の時間の欠片（思い出写真・言葉の欠片・金の歯車・月夜の約束・再会の星砂）を縫い繋ぎ、「今夜の壊れた時間」を修繕。
  - 2つの欠片を結ぶ**すれ違いペア（TIME LINK）**や、針を逆回転させて文字盤上の「時のほころび」を一斉浄化する**巻き戻し（REWIND STITCH）**を搭載。
  - ゲージMAXで **GOLDEN HOUR（黄金の刻）**発動！押し入れの隙間から黄金の光が満ち、全ほころびが再会の星砂へ変化＆2倍スコアの爽快フィーバー！
  - 公式3アレンジ（`Dreamy Ver.` / `通常版` / `Instrumental` 各62秒ゲームサイズ）、6種類の工房設備強化（修復キット・振り子柱時計・金糸ボビン・思い出の瓶棚・真鍮砂時計・写真立てが3D空間に反映）、物語『第三話：押し入れの奥の時間職人』全5章を収録。

### 01. 記憶の香り鍋 〜ススノミ〜
- **ジャンル**：3D 換気口キッチン・香りキャッチ＆記憶調理アクション（[`susunomi.html`](susunomi.html)）
- **舞台**：古びたアパートの「換気口の奥の小さな台所」
- **特徴**：
  - リグ・アニメーション済み `susunomi.glb`（`Walking` / `Running`）＋青いガス火の上で光る銅鍋＆木べらを搭載。
  - タッチドラッグや矢印キーで銅鍋を動かし、換気口から漂う5色の光の匂い（焼き魚・カレー・焼きたてパン・あたたか出汁・星灯りの記憶）を集めて「今夜の記憶レシピ」を完成させよう。
  - **木べらかき混ぜ（STIR BURST）**で焦げ煙を浄化＆周囲の匂いを一気に銅鍋へ引き寄せ。
  - ゲージMAXで **KOTOKOTO FEVER（ことことフィーバー）**発動！朝の光が差し込み、全レーン吸引＆焦げ煙が星灯りへ変化する爽快フィーバー！
  - 公式3アレンジ（`Dreamy Ver.` / `通常版` / `Instrumental` 各62秒ゲームサイズ）、6種類の台所設備強化（香り瓶棚・レシピ額・マッチ箱ベッド・銅やかん等が3D空間に反映）、物語『第一話：換気口の奥の料理人』全5章を収録。

### 02. 終電のランタン 〜カゲミチ〜
- **ジャンル**：3D 夜行ホーム・ランタンランナー＆夢送りアクション（[`kagemichi.html`](kagemichi.html)）
- **舞台**：終電がいってしまったあとの「おわりの駅（終点ホーム＆見えないレール）」
- **特徴**：
  - リグ・アニメーション済み `kagemichi.glb`（`Walking` / `Running`）＋右手に揺れる真鍮ランタンを搭載。
  - 3レーン移動＆ジャンプで「帰れなかった想い」（言えなかったありがとう・渡せなかった手紙・しまいこんだ気持ち・消えなかった温度・再会の夢切符）を集め、迷い霧や遮断バーを回避。
  - ランタン満タンで**夢送り（DREAM SENT）**→「夢の切符」を獲得。
  - ゲージMAXで **DREAM EXPRESS** 発動！夢行きの終電列車がホーム横を並走し、全レーン吸引＆無敵2倍の爽快フィーバー！
  - 公式3アレンジ（`Dreamy Ver.` / `通常版` / `Instrumental` 各62秒ゲームサイズ）、6種類の詰め所・駅設備強化、物語『第二話：電車の終点に立つ案内人』全5章を収録。

### 12. 涙蔵のオルゴール 〜ナミダビン〜
- **ジャンル**：3D 箱庭リズム＆宝石クラフト（[`namidabin.html`](namidabin.html)）
- **舞台**：常世町の地下にある青い光の「涙蔵（なみだぐら）」
- **特徴**：
  - リグ・アニメーション済み `namidabin.glb`＋リアルタイム3D地下蔵空間。
  - 公式3アレンジ楽曲に合わせて5色の涙結晶をタップ＆スワイプ連鎖回収、中央台座で4拍リズム研磨して宝石へ昇華。
  - 6種類の蔵設備強化、正の字記録、記憶エピソード全5章を収録。

## ローカル起動・ビルド

```bash
npm install
npm run dev
```

プロダクションビルド：

```bash
npm run build
```

```text
├── index.html                  # 見えない隣人たち ゲーム選択ポータル
├── nukumori.html               # 05. 自販機裏のぬくもり番 〜ヌクモリ〜
├── wasuredama.html             # 04. 街灯の下のわすれ玉 〜ワスレダマ〜
├── tokitsugi.html              # 03. 時繋ぎの懐中時計 〜トキツギ〜
├── susunomi.html               # 01. 記憶の香り鍋 〜ススノミ〜
├── kagemichi.html              # 02. 終電のランタン 〜カゲミチ〜
├── namidabin.html              # 12. 涙蔵のオルゴール 〜ナミダビン〜
├── public/assets/
│   ├── models/                 # nukumori.glb / wasuredama.glb / tokitsugi.glb / susunomi.glb / kagemichi.glb / namidabin.glb
│   ├── audio/                  # 各キャラクター公式3バージョン（MP3）
│   └── images/                 # ポータル用キャラクターサムネイル
└── src/
    ├── portal.ts / portal.css  # 常世町ポータル
    ├── nukumori/               # ヌクモリ 3D真冬の自販機裏＆ベンチ広場（scene/actor/system/audio/state/ui）
    ├── wasuredama/             # ワスレダマ 3D街灯の広場（scene/actor/system/audio/state/ui）
    ├── tokitsugi/              # トキツギ 3D押し入れ時計工房（scene/actor/system/audio/state/ui）
    ├── susunomi/               # ススノミ 3D換気口キッチン（scene/actor/system/audio/state/ui）
    ├── kagemichi/              # カゲミチ 3Dランナー（scene/actor/runner/audio/state/ui）
    └── game/                   # ナミダビン 3Dリズム＆箱庭（vault/actor/rhythm/audio/state/ui）
```
