# 涙蔵のオルゴール 〜ナミダビン〜（プロトタイプ）

『**見えない隣人たち**』の世界観・キャラクター・楽曲・3Dモデルを活用した、スマホ横画面＆WebGL対応の**3D箱庭リズム＆クラフトゲーム**プロトタイプです。

常世町の地下にある「涙蔵（なみだぐら）」を舞台に、涙瓶職人**ナミダビン**とともに、音楽のビートに合わせて5色の涙の結晶を集め、宝石へと磨き上げていきます。

---

## 主な特徴（v0.1 プロトタイプ）

- **実3Dモデル＆地下「涙蔵」空間（Three.js）**
  - リグ・アニメーション済み `namidabin.glb`（`Walking` / `Running`）を搭載。タップした結晶や台座へ向かってナミダビンが駆け寄ります。
  - アーチ天井の地下室、数百本の涙瓶棚、床のメダリオン、中央の宝石台座、作業台、ラベル机、移動はしご、荷車など、涙蔵の空間をリアルタイム3Dで再現。
- **3バージョンの楽曲アレンジを完全活用（Web Audio API）**
  - 🌙 `Dreamy Ver.`（癒やし育成）
  - ✨ `Original`（軽快なリズム採集）
  - 🔥 `Digital Math Punk Remix`（ゲージMAXで突入する超高速フィーバー **CRYSTAL RUSH**！）
- **テンポ感と中毒性を両立するコアサイクル**
  1. **ビート採集**：曲に合わせて湧く5種の涙結晶（悲しい・くやしい・うれしい・さよなら・また会えた）をジャストタップ＆スワイプ連鎖で回収。
  2. **台座リズム研磨 → 宝石昇華**：採集瓶が満タンになると中央台座で4拍リズム研磨し、**Beautiful Crystal** として宝石へ昇華。
  3. **蔵のしつらえ＆記憶ラベル**：集めた結晶・宝石で6種類の設備を強化すると、3Dの棚の点灯数・はしごの巡回・荷車の瓶・台座の宝石が実際に進化し、少女の一年間の記憶エピソード（全5章）が解放されます。
- **操作対応**：スマホ横画面（タップ＆スワイプ）／PC（マウスクリック・ドラッグ・`Space`/`Z`/`X`/`J`/`K`キー、フィーバー発動 `F`）

## ローカル起動方法

```bash
npm install
npm run dev
```

ビルド確認：

```bash
npm run build
```

## プロジェクト構成

```text
├── index.html                  # 横画面最適化レイアウト & HUD
├── public/assets/
│   ├── models/namidabin.glb    # ナミダビン 3Dモデル（Walking/Running）
│   └── audio/                  # ナミダビン楽曲3アレンジ（MP3）
└── src/
    ├── main.ts                 # エントリーポイント & メインループ
    ├── style.css               # 夜の硝子×金箔HUDスタイル
    └── game/
        ├── types.ts            # 型定義
        ├── config.ts           # 5種の涙・3楽曲・6設備・5章ストーリー定義
        ├── state.ts            # セーブ管理（localStorage）＆オフライン荷車収入
        ├── audioEngine.ts      # Web Audio 同期・クロスフェード・ガラス音階SE
        ├── vaultScene.ts       # Three.js「涙蔵」3D空間 & 設備進化演出
        ├── namidabinActor.ts   # ナミダビン3Dアニメ & 移動制御
        ├── rhythmSystem.ts     # ビート採集・スワイプ連鎖・研磨・CRYSTAL RUSH
        └── uiController.ts     # HUD・正の字実績・蔵のしつらえ・記憶帳・設定
```
